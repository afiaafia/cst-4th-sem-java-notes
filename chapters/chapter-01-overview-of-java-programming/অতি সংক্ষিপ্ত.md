# অধ্যায়-১: জাভা প্রোগ্রামিং-এর ধারণা
## অতি সংক্ষিপ্ত প্রশ্নাবলী (১-১০)

### ১। জাভায় ব্যবহৃত ১০টি Keyword এর নাম লেখ।
**অথবা, পাঁচটী ছাড়া কী ভাষার ৩টি ওভারফ্লো নাম লেখ।**  
**অথবা, পাঁচটি Java keyword-এর নাম লেখ।**  
**অথবা, জাভায় ব্যবহৃত ১০টি Keyword উল্লেখ কর—**  
**উঃ** break, byte, case, char, do, else, go to, null, return, switch.

---

### ২। JDK কী?
**অথবা, JDK বলতে কী বোঝায়?**  
**অথবা, JDK বানাতে কী বুঝায়?**  
**উঃ** JDK এর পূর্ণনাম Java Development Kit। প্রোগ্রামের কম্পাইলার এবং ডেভেলপমেন্টের জন্য প্রয়োজনীয় ড্রাফ ও সফটওয়্যার উপাদানসমূহের সমন্বয়ে গঠিত প্যাকেজই হলো JDK।

---

### ৩। JVM বলতে কী বোঝায়?
**অথবা, Java-তে 'JVM' বলা হয় কেন?**  
**অথবা, JVM কী?**  
**উঃ** Java Virtual Machine কে সংক্ষেপে JVM বলে। এটি একটি কাল্পনিক Machine, যা Computer এর Memory তে অবস্থান করে Byte code তৈরি করে।

---

### ৪। Keyword কী?
**অথবা, Keyword বলতে কী বোঝায়?**  
**উঃ** Keyword হলো এমন প্রোগ্রামিং ভাষার ভাষা সম্পর্কিত কিছু শব্দ, যা কম্পাইলারের কাছে বিশেষ অর্থ বহন করে। যেমন— `class`, `int`, `char` ইত্যাদি।

---

### ৫। Java keyword এর নাম ও সংখ্যা লেখ।
**অথবা, Keyword এর নাম ও কাজ লেখ।**  
**উঃ** জাভায় ৩০টি Keyword রয়েছে। যেমন: `class`, `int`, `char` ইত্যাদি।  
- (i) `class` – এই keyword-টি ক্লাস তৈরি করার জন্য ব্যবহৃত হয়।  
- (ii) `package` – এই keyword-টি প্যাকেজ তৈরি করার জন্য ব্যবহৃত হয়।

---

### ৬। Final keyword কী?
**উঃ** Final keyword হলো একটি বিশেষ কি-ওয়ার্ড। এটি কোনো ভ্যারিয়েবল, মেথড ও ক্লাসকে অপরিবর্তনীয় ব্যবহার করার জন্য ব্যবহার করা হয়।

---

### ৭। Separator ও White space কী?
**উঃ** 
- **Separator (সেপারেটর):** সেপারেটর হিসাবে ব্যাক স্ল্যাশ (`\`) ব্র্যাকেটের মতো ব্যবহৃত হয়। সাধারণত ফাইল বা ডিরেক্টরির পাথ (`path`) নির্দেশ করার জন্য সেপারেটর ব্যবহার করা হয়।
- **White Space (ফাঁকা স্থান):** কোনো প্রোগ্রামিং ভাষায় ব্যবহৃত ক্যারেক্টার ও ডাবল কোটেশন ও টার্ম এর মধ্যকার খালি ব্যবসাকে white space বলে। Tabs, line-feeds এবং carriage return (Enter) ইত্যাদি white space হিসেবে বিবেচিত হয়।

---

### ৮। কিবোর্ড কবে ও কোথায় আবিষ্কৃত হয়?
**অথবা, Java কখন ও কোথায় আবিষ্কৃত হয়?**  
**উঃ** Sun Microsystems কোম্পানীতে গবেষক James Gosling এর নেতৃত্বে একদল (প্রথমবার Green প্রজেক্টের আওতায়) ১৯৯৫ সালে জাভা সর্বপ্রথম সর্বসাধারণের সামনে প্রকাশ করেন।

---

### ৯। কনসোল মোড কী বা কখন ব্যবহৃত হয়?
**অথবা, Java console বলতে কী বোঝায়?**  
**উঃ** সাধারণত C-প্রোগ্রামিং মোডে ব্যবহৃত হয়।

---

### ১০। Separator ও Comment কী?
**উঃ** 
- **Comments (কমেন্ট):** برنامে অনেক সময় পরবর্তী সময়ে নিচে কিছু দুবার জন্য কিংবা অন্যকে কিছু বোঝানোর জন্য কমেন্টিং বা মন্তব্য লিখে রাখা হয়। প্রথম নির্দেশে কমান্ডের কোনো ভূমিকা নেই। সিঙ্গেল লাইন কমেন্টে ডাবল স্ল্যাশ (`//`) ব্যবহৃত হয়। অপরদিকে মাল্টি লাইন কমেন্টে `/*` দিয়ে শুরু হয় এবং `*/` দিয়ে শেষ হয়। `/**` এবং `*/` এর মাধ্যমে ডকুমেন্টেশন কমেন্ট চিহ্নিত করা হয়।
- **Separator (সেপারেটর):** সেপারেটর হিসেবে ব্যাক স্ল্যাশ (`\`) ব্র্যাকেটের ব্যবহৃত হয়। সাধারণত ফাইল বা ডিরেক্টরির নাম (`path`) নির্দেশ করার জন্য সেপারেটর ব্যবহার করা হয়।

---

### ১১। Identifier কী?
**অথবা, Identifier বলতে কী বোঝায়?**[cite: 13]  
**উঃ** প্রোগ্রামে ব্যবহৃত Variable, constant, class, object, label, structure, pointer, array, method ইত্যাদিকে Identify করার জন্য যে নাম বা শব্দ ব্যবহার করা হয়, তাকে Identifier বলে[cite: 13]।

---

### ১২। মেইন মেথড [main ( ) method] কী?
**উঃ** প্রতিটি জাভা প্রোগ্রামে একটি মাত্র main ( ) method এর মাধ্যমে। main ( ) method বিভিন্ন Class এর Object তৈরি করে এবং এদের মধ্যে Communication এর ব্যবস্থা করে[cite: 13]। এর Declaration নিম্নরূপ—  
`public static void main (String args [ ])`[cite: 13]

---

### ১৩। Java programming এর প্রয়োগক্ষেত্র উল্লেখ কর।
**অথবা, Java ভাষার প্রধান তিনটি প্রধান প্রয়োগক্ষেত্র রয়েছে, যথা—**[cite: 13]  
**উঃ**  
(i) কনসোল মোড অ্যাপ্লিকেশন এবং[cite: 13]  
(ii) গ্রাফিক্যাল ইউজার ইন্টারফেস অ্যাপ্লিকেশন[cite: 13]  
(iii) অ্যাপলেট অ্যাপ্লিকেশন।[cite: 13]

---

### ১৪। Java কী?
**উঃ** অবজেক্ট অরিয়েন্টেড প্রোগ্রামিং এর জগতে সর্বশ্রেষ্ঠ ও আধুনিক সংযোজন হচ্ছে জাভা (Java)[cite: 13]। জাভা একটি সত্যিকারের পূর্ণাঙ্গ অবজেক্ট অরিয়েন্টেড প্রোগ্রামিং ল্যাঙ্গুয়েজ[cite: 13]। কারণ অবজেক্ট অরিয়েন্টেড প্রোগ্রামিংয়ের প্রধান তিনটি বৈশিষ্ট্য, যেমন- পলিমরফিজম (Polymorphism), ইনহেরিটেন্স (Inheritance) এবং এনক্যাপসুলেশন (Encapsulation) সহ অন্যান্য যেসব বৈশিষ্ট্য থাকা প্রয়োজন তার সবকিছুই জাভাতে আছে[cite: 13]। ফলে জাভা সহজ, সরল, সাবলীল, বিশুদ্ধ ও পূর্ণাঙ্গ অবজেক্ট অরিয়েন্টেড প্রোগ্রামিং[cite: 13]।

---

### ১৫। GUI মোড কী?
**উঃ** জাভাতে গ্রাফিক্যাল অর্থাৎ ইউজারফ্রেন্ডলি অ্যাপ্লিকেশন তৈরিতে যে মোডে প্রোগ্রাম রচনা করা হয়, তাকে GUI মোড বলে[cite: 13]।

---

### ১৬। GUI মোডের জন্য প্রয়োজনীয় প্যাকেজের নাম কী?
**উঃ** GUI মোডের জন্য অত্যন্ত প্রয়োজনীয় প্যাকেজটি হচ্ছে AWT (Abstract windowing Toolkit) java.awt প্যাকেজ ইম্পোর্ট করে GUI mode এর কাজগুলো করা যায়[cite: 13]।

---

### ১৭। জাভাতে সিঙ্গেল লাইন কমেন্টিং ও মাল্টি লাইন কমেন্টিং লেখার নিয়ম কী?
**উঃ** জাভায় সিঙ্গেল লাইন কমেন্টিং লেখার জন্য দুটি স্ল্যাশ (`//`) এবং মাল্টি লাইন কমেন্টিং লেখার ক্ষেত্রে কমেন্টস `/*` দিয়ে শুরু হয় এবং `*/` দিয়ে শেষ হয়[cite: 13]।

---

### ১৮। সেপারেটর (/) ব্যবহার করা হয় কেন?
**উঃ** সাধারণত ফাইল বা ডিরেক্টরির পাথ (Path) নির্দেশ করার জন্য সেপারেটর (`/`) ব্যবহার করা হয়[cite: 13]।
