### ১। জাভার বৈশিষ্ট্যগুলো কী কী?
**অথবা, Java programming-এর বৈশিষ্ট্যগুলো লেখ।**  
**উঃ** জাভার বৈশিষ্ট্যগুলো নিম্নরূপ—  
(i) অবজেক্ট ওরিয়েন্টেড (Object oriented)  
(ii) কম্পাইল্ড ও ইন্টারপ্রেটেড (Both compiled and interpreted)  
(iii) প্ল্যাটফর্ম অনির্ভরশীলতা (Platform independent)

(vii) শক্তিশালী ও নিরাপদ (Robust and secure)  
(viii) গতিশীল ও সম্প্রসারণযোগ্য (Dynamic and extensible)

### ২। জাভাকে যন্ত্র নিরপেক্ষ ভাষা বলা হয় কেন?
**অথবা, Java platform independent ব্যাখ্যা কর।**  
**উঃ** প্রোগ্রাম ভাষাগুলো সাধারণত কম্পাইলার অথবা ইন্টারপ্রেটার অনুবাদিত হয়। কম্পাইলারের অনুবাদিত প্রোগ্রাম ভাষাগুলো মেশিন নির্ভর হয়, অর্থাৎ এক ধরনের মেশিন ও অপারেটিং সিস্টেম কর্তৃক অনুবাদিত প্রোগ্রাম ভিন্ন ধরনের মেশিন ও অপারেটিং সিস্টেমে রান করে না। কিন্তু জাভা কম্পাইলার ও ইন্টারপ্রেটার উভয় কর্তৃক অনুবাদযোগ্য। এজন্য জাভাকে একটি দ্বি-পর্যায় (Two-stage) বিশিষ্ট ল্যাঙ্গুয়েজ বলা হয়। প্রথম পর্যায়ে সোর্স প্রোগ্রাম কম্পাইলার কর্তৃক অনুবাদিত হয়ে বাইটকোডে (bytecode) রূপান্তরিত হয়। দ্বিতীয় পর্যায়ে জাভা ইন্টারপ্রেটার কর্তৃক জাভা ব্যবহারকারী মেশিনের বোধগম্য মেশিন কোডে পরিণত হয়। এজন্য জাভাকে কম্পাইলার এবং ইন্টারপ্রেটার উভয় কর্তৃক অনুবাদিত একটি যন্ত্র নিরপেক্ষ প্রোগ্রাম ভাষা বলা হয়।

### ৪। Java program-এর ক্ষেত্রে comments লেখার পদ্ধতি লেখ।
**উঃ** কমেন্টস্ (Comments) : প্রোগ্রামে অনেক সময় পরবর্তী সময়ে নিজে কিছু বোঝার জন্য কিংবা অন্যকে কিছু বোঝানোর জন্য কমেন্টস বা মন্তব্য লিখে রাখা হয়। প্রোগ্রাম নির্দেশে কমেন্টের কোনো ভূমিকা নেই। সিঙ্গেল লাইন কমেন্টে দুটো স্ল্যাশ (`//`) ব্যবহৃত হয়। অপরদিকে মাল্টি লাইন কমেন্ট `/*` দিয়ে শুরু হয় এবং `*/` দিয়ে শেষ হয়। `/**` এবং `*/` এর মাধ্যমে ডকুমেন্টেশন কমেন্ট হিসেবে বিবেচিত হবে[cite: 15]।

**উদাহরণ :**[cite: 15]
```java
sum = sum + x; // This is a single line comment
/*
sum = sum + x; / "This program is used to find out
                 the summation of a series" /
*/
```[cite: 15]

### ৫। জাভাতে মূলত কত ধরনের প্রোগ্রাম তৈরি করা যায়? সংক্ষেপে বর্ণনা কর।
**অথবা, Java-এর প্রয়োগক্ষেত্রগুলো সংক্ষেপে লেখ।**[cite: 15]  
**উঃ** জাভা ভাষার ব্যবহারিক ক্ষেত্র বা প্রয়োগক্ষেত্র বিশাল ও ব্যাপক। তবে প্রধান ৩ ধরনের প্রোগ্রাম ফ্রেমওয়ার্ক হিসেবে চিহ্নিত করা যায়, যথা—[cite: 15]

(i) কনসোল মোড অ্যাপ্লিকেশন (Console mode application)[cite: 15]  
(ii) গ্রাফিক্যাল ইউজার ইন্টারফেস অ্যাপ্লিকেশন (GUI application) এবং[cite: 15]  
(iii) অ্যাপলেট (Applet) ইত্যাদি।[cite: 15]

- **কনসোল মোড অ্যাপ্লিকেশন (Console mode application) :** Console mode application-কে গ্রাফিক্স হাসানের দিক থেকে DOS-এর সাথে তুলনা করা যায়। DOS মূলত একটি Console mode Operating System। বিভিন্ন ধরনের টেক্সট ভিত্তিক উইন্ডো গ্রাফিক্স মোডে রচনা করা যায়। এখানে গ্রাফিক্যাল কোনো স্থান নেই, সব কাজ করার জন্য টেক্সট ব্যবহার করে। গ্রাফিক্স না থাকায় স্ক্রিন এরোর এর প্রোগ্রাম GUI প্রোগ্রামের তুলনায় দ্রতগতিসম্পন্ন এবং এদের Overhead কম। সাধারণত সার্ভিস সফটওয়্যার গ্রাফিক্যাল ইন্টারফেস না থাকলে ব্যবহার করা হয়[cite: 15]।
- **গ্রাফিক্যাল ইউজার ইন্টারফেস অ্যাপ্লিকেশন (GUI application) :** GUI-এর পূর্ণরূপ হচ্ছে- Graphical User Interface। প্রতিটি Standard language-এরই GUI component উপাদান রয়েছে। অন্য অন্যাদের সাথে Java এর মূল পার্থক্য হচ্ছে portability। Java language দ্বারা তৈরি একটি graphical user interface যেকোনো platform যেমন Sun workstation, IBM-compatible PC, Macintosh এবং অন্যান্য অনেক ধরনের platform-এ চলবে। Java AWT এই অন্যান্য ব্যবহারিককে বাস্তব রূপ দিয়েছে[cite: 15]।

### ৬। জাভায় প্রোগ্রাম লেখার নিয়মাবলী কী?
**অথবা, Java-তে Program লেখার নিয়ম লেখ।**[cite: 15]  
**উঃ** প্রোগ্রামের সৌন্দর্য ও readability বৃদ্ধির জন্য জাভায় প্রোগ্রাম লেখার ক্ষেত্রে নিম্নলিখিত নিয়মাবলি মেনে চলা উচিত, যেমন—[cite: 15]

(i) Class header এর শেষে বা পরবর্তী লাইনে Opening brace ` "{" ` বসানো উচিত।[cite: 15]  
(ii) Opening brace এর ` "{" ` পরের লাইনে একে এক এক Tab position ডান দিকে সরে গিয়ে Class body লেখা শুরু করা উচিত, যাতে—[cite: 15]  
(iii) প্রতিটি ব্লকের ভেতরের আরেকটা ব্লক থাকলে সেটার জন্য আরও একটি Tab position ডানে গিয়ে Indent করে লেখা উচিত[cite: 15]।  
(iv) প্রতিটি Statement আলাদা লাইনে লেখা উচিত[cite: 15]।

### ৭। জাভা ভার্চুয়াল মেশিন (JVM) ব্যবহার করা হয় কেন? ব্যাখ্যা কর।
**অথবা, জাভা একটি Virtual machine (VM)—ব্যাখ্যা কর।**  
**অথবা, Java-কে JVM বলা হয় কেন? ব্যাখ্যা কর।**[cite: 16]  
**উঃ** যে-কোনো হাই লেভেল ল্যাঙ্গুয়েজ-এর সোর্স কোডকে মেশিনের বোঝাপড়া উপযোগী করার জন্য বা মেমোরিতে রান করার জন্য কম্পাইলারের প্রয়োজন হয়[cite: 16]। যেখানে অন্যান্য ল্যাঙ্গুয়েজ লজিক্যাল অপারেটিং সিস্টেম ভেদে আলাদা আলাদা কম্পাইলার দিয়ে সোর্স কোডকে কম্পাইল করতে হয়, অর্থাৎ সোর্স কোডকে সরাসরি মেশিন কোডে রূপান্তরিত করে, ফলে কম্পাইলারের জন্য অ্যাপ্লেট বা মেমোরি খরচ বেশি হয়[cite: 16]। জাভা কিন্তু কোন বাস্তব মেশিন নয়, এটি একটি virtual machine, এটি অবস্থান করে কম্পিউটারের মেমোরিতে[cite: 16]। এটি ভিন্ন কম্পিউটারের ভেতরের স্থান অন্য প্রসেসর ও মেমোরিতে তৈরি করে যেন যেকোনো জায়গায় একই রকম কাজ ও ইন্টারপ্রিটিং সমানভাবে করা যায়[cite: 16]। একে বলা হয় জাভা ভার্চুয়াল মেশিন (Java Virtual Machine) সংক্ষেপে JVM[cite: 16]। সুতরাং জাভা ভার্চুয়াল মেশিন (JVM) হচ্ছে এমন একটি সফটওয়্যার প্রসেসর যা সোর্স কোডকে প্রথমে বাইট কোডে (Byte code) ও পরবর্তীতে মেশিন কোডে (Machine code)-এ রূপান্তর করে[cite: 16]।

### ৯। জাভাকে পূর্ণাঙ্গ অবজেক্ট অরিয়েন্টেড ল্যাঙ্গুয়েজ বলা হয় কেন?
**উঃ** জাভা একটি সত্যিকার গতিসভার অবজেক্ট অরিয়েন্টেড ভাষা[cite: 16]। সুতরাং এর এনক্যাপসুলেশন, তথ্য ও অবজেক্টের নিরাপদ ও পূর্ণাঙ্গ ডেটা ডেফিনিশন নির্ভর করে[cite: 16]। সাধারণ অবজেক্টের ক্লাসের দ্বারা নতুন ডেটা তৈরি করা যায়[cite: 16]। ইনহেরিটেন্স প্রক্রিয়ায় পুরাতন এক বা একাধিক ক্লাসের ডেটা ধারণ করে নতুন নতুন ক্লাসের জন্ম দেওয়া যায়[cite: 16]। ৪ নম্বর বিষয় হলো এক বা একাধিক অবজেক্টের স্থান বা পদ্ধতিকে নিয়ন্ত্রণ করার জন্য পলিমরফিজম প্রয়োগ করা যায়[cite: 16]। Object Oriented design মূলত ওপরের ৪টি কৌশল- OOP সার্পোট করে[cite: 16]। Polymorphism, Inheritance এবং Encapsulation এর একটি OOP language এর যা কিছু থাকা দরকার তার সবকিছুই জাভাতে রয়েছে[cite: 16]। সুতরাং জাভাকে নির্বিচারে বলা যায় এটি Object Oriented Language[cite: 16]।

### ১০। জাভা ও সি++ এর মধ্যে চারটি পার্থক্য লেখ।
**অথবা, C++ এবং জাভার চারটি পার্থক্য লেখ।**  
**অথবা, নিচে জাভা ও সি++ কাঠামোগত পার্থক্য উল্লেখ করা হলো :**[cite: 16]  
**উঃ** 

| ক্রমিক নং | জাভা (Java) | সি++ (C++) |
| :--- | :--- | :--- |
| ১ | জাভা একটি পূর্ণাঙ্গ অবজেক্ট অরিয়েন্টেড ল্যাঙ্গুয়েজ যার মাধ্যমে তিন ধরনের প্রোগ্রাম (কনসোল মোড অ্যাপ্লিকেশন (Console mode Application), গ্রাফিক্যাল ইন্টারফেস অ্যাপ্লিকেশন (GUI Application) ও অ্যাপলেট (Applet) ইত্যাদি) রচনা করা যায়। | সি++ এ অবজেক্ট অরিয়েন্টেড প্রোগ্রামিং ল্যাঙ্গুয়েজ যার মাধ্যমে দুই ধরনের প্রোগ্রাম (কনসোল মোড অ্যাপ্লিকেশন (Console mode application) ও জিইউআই (GUI) অ্যাপ্লিকেশন) রচনা করা যায়। |
