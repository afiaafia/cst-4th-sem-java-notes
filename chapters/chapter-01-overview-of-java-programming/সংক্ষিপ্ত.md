# অধ্যায়-১: জাভা প্রোগ্রামিং-এর ধারণা
## সংক্ষিপ্ত প্রশ্নাবলী[cite: 7, 8, 9, 10]

### ১। জাভা প্রোগ্রামিং-এর বৈশিষ্ট্যগুলো লেখ।[cite: 7, 12]
**উঃ** জাভা প্রোগ্রামিং-এর প্রধান বৈশিষ্ট্যসমূহ নিচে দেওয়া হলো:[cite: 7, 12]
1. **অবজেক্ট অরিয়েন্টেড (Object oriented):** এটি একটি গতিশীল অবজেক্ট অরিয়েন্টেড প্রোগ্রামিং ভাষা[cite: 7, 12].
2. **কম্পাইল্ড ও ইন্টারপ্রেটেড (Both compiled and interpreted):** জাভা কোড প্রথমে কম্পাইলার দ্বারা বাইট কোডে রূপান্তরিত হয় এবং পরে ইন্টারপ্রেটার দ্বারা মেশিন কোডে রূপান্তরিত হয়[cite: 7, 12].
3. **প্ল্যাটফর্ম স্বাধীনতানির্ভর (Platform independent):** Write Once, Run Anywhere (WORA)[cite: 7, 12].
4. **পোর্টেবল (Portable)**[cite: 7, 12]
5. **উচ্চ ক্ষমতাসম্পন্ন (Highly efficient)**[cite: 7, 12]
6. **সহজ, সাবলীল ও ছোট (Easier, simple and small)**[cite: 7, 12]
7. **শক্তিশালী ও নিরাপদ (Robust and secure)**[cite: 7, 12]
8. **গতিশীল ও সম্প্রসারণযোগ্য (Dynamic and extensible)**[cite: 7, 12]
9. **ডিস্টিবিউটেড (Distributed)**[cite: 7, 12]
10. **মাল্টিথ্রেডেড (Multithreaded)**[cite: 7, 12]

---

### ২। জাভাকে কেন platform independent ব্যাখ্যা কর।[cite: 7, 12]
**উঃ** Java ভাষায় লিখিত সোর্স কোড সরাসরি কোনো অপারেটিং সিস্টেমের দ্বারা কম্পাইল হয়ে সরাসরি মেশিন ভাষায় রূপান্তর হয় না, কম্পাইলার কর্তৃক রূপান্তরিত হয় প্রাথমিক জাভা bytecode (byte code) এ[cite: 7, 12]. এরপর জাভা ভার্চুয়াল মেশিন (JVM) কর্তৃক উক্ত bytecode কে সংশ্লিষ্ট মেশিনের উপযোগী মেশিন কোডে রূপান্তরিত করা হয়[cite: 7, 12]. এ জন্য জাভাকে প্ল্যাটফর্ম ইন্ডিপেন্ডেন্ট বলা হয়[cite: 7, 12].

---

### ৩। Identifier কী? Identifier বানাতে কী সতর্কতা থাকতে হবে?[cite: 7, 12]
**উঃ** 
- **Identifier:** কোনো জাভা প্রোগ্রামে ব্যবহৃত Variable, constant, class, object, label, structure, pointer, array, method ইত্যাদিকে identifier বলে[cite: 7, 12].
- **Identifier তৈরির ক্ষেত্রে সতর্কতা বা নিয়ম:**[cite: 7, 12]
  (i) জাভা প্রোগ্রামিং এ অক্ষর অথবা `$` sign অথবা underscore (`_`) থাকতে হবে[cite: 7, 12].  
  (ii) সংখ্যা দিয়ে শুরু করা যাবে না[cite: 7, 12].

---

### ৪। Java Programming এর প্রধান বৈচিত্র্যকরণ কী?[cite: 7, 12]
**উঃ** জাভা প্রোগ্রামিংয়ের প্রধান বৈচিত্র্যকরণ বা ব্যবহার ক্ষেত্রগুলো হলো—[cite: 7, 12]
- (i) অ্যাপ্লিকেশন সফটওয়্যার অ্যাপ্লিকেশন (Console mode application / GUI application)[cite: 7, 12]
- (ii) অ্যাপলেট (Applet) ইত্যাদি[cite: 7, 12]

---

### ৫। Java প্রোগ্রামের লেখার নিয়মাবলী কী?[cite: 8]
**উঃ** 
- (i) Class header এর শেষে বা গতির গায়েলে Opening brace `"{"` বসানো চিহ্নিত[cite: 8].
- (ii) Opening brace এর `"{"` পরের লাইনে Indent Position জন্য নিচে গিয়ে Class body লেখা শুরু করা উচিত[cite: 8].
- (iii) প্রতিটি Statement আলাদা লাইনে লেখা উচিত[cite: 8].

---

### ৬। জাভা ভার্চুয়াল মেশিন (JVM) ব্যবহার করা হয় কেন? / কেন ব্যাখ্যা কর?[cite: 8, 9, 10]
**উঃ** Java-তে সরাসরি কোনো সোর্স কোড সরাসরি মেশিন ভাষায় রূপান্তরিত হয় না[cite: 8, 9, 10]. সোর্স কোড প্রথমে বাইট কোড (Byte code)-এ রূপান্তরিত হয়[cite: 8, 9, 10]. এই বাইট কোড যেকোনো মেশিনের জন্য সরাসরি বোধগম্য নয়[cite: 8, 9, 10]. এক্ষেত্রে JVM (Java Virtual Machine) অত্যন্ত গুরুত্বপূর্ণ ভূমিকা পালন করে[cite: 8, 9, 10]. JVM একটি সফটওয়্যার প্রসেসর যা বাইট কোডকে সংশ্লিষ্ট মেশিনের উপযোগী মেশিন কোডে রূপান্তর করে[cite: 8, 9, 10].

### ৭। জাভা ও সি++ এর মধ্যে পার্থক্য লেখ।[cite: 9]
**উঃ** নিচে জাভা (Java) ও সি++ (C++) এর মধ্যে পার্থক্য দেওয়া হলো:[cite: 9]

| ক্রমিক নং | বৈশিষ্ট্য | Java[cite: 9] | C++[cite: 9] |
| :--- | :--- | :--- | :--- |
| ১ | অবজেক্ট অরিয়েন্টেড | জাভা একটি পুরোপুরি অবজেক্টঅরিয়েন্টেড প্রোগ্রামিং ভাষা[cite: 9]. | C++ অবজেক্টঅরিয়েন্টেড হলেও এটি pure object oriented নয়[cite: 9]. |
| ২ | পয়েন্টার (Pointer) | জাভায় পয়েন্টারের সরাসরি ব্যবহার করা যায় না[cite: 9]. | C++ এ পয়েন্টারের সরাসরি ব্যবহার করা যায়[cite: 9]. |
| ৩ | প্রিপ্রসেসর ডিরেক্টিভ | জাভায় `#include`, `#define` প্রিপ্রসেসর ডিরেক্টিভ ব্যবহার করা যায় না[cite: 9]. | C++ এ `#include`, `#define` প্রিপ্রসেসর ডিরেক্টিভ ব্যবহার করা যায়[cite: 9]. |
| ৪ | মেমোরি ম্যানেজমেন্ট | জাভায় গারবেজ কালেকশন স্বয়ংক্রিয়ভাবে হয়[cite: 9]. | C++ এ মেমোরি ম্যানেজমেন্ট বা গারবেজ কালেকশন স্বয়ংক্রিয়ভাবে হয় না[cite: 9]. |
| ৫ | ওভারলোডিং | জাভা শুধু মেথড ওভারলোডিং সমর্থন করে[cite: 9]. | C++ এ মেথড ওভারলোডিং এবং অপারেটর ওভারলোডিং উভয়ই সমর্থন করে[cite: 9]. |
